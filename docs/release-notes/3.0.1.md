# ROV Overlay Tool 3.0.1

แก้บั๊กสำคัญ: **เปิดโปรแกรมครั้งแรกแล้วไม่มีอะไรขึ้นเลย**

หน้าต่างเงื่อนไขการใช้งานถูกสั่งให้เปิดก่อนที่ตัวโปรแกรมจะพร้อม หน้าต่างนั้นจึงไม่ถูกสร้างขึ้นมาจริง ๆ
ผลคือโปรแกรมค้างรออยู่เงียบ ๆ ไม่มีหน้าต่าง ไม่มีข้อความบอก มีแต่โปรเซสที่ยังทำงานอยู่

ตอนนี้หน้าต่างหลักขึ้นก่อน แล้วเงื่อนไขการใช้งานค่อยเปิดซ้อนบนหน้าต่างนั้น

และถ้าต่อไปมีอะไรพังตอนเปิดโปรแกรม จะมีข้อความบอกพร้อมบันทึกไว้ที่
`%APPDATA%\RovOverlayTool3\startup-error.log` แทนที่จะเงียบแบบเดิม

ถ้าคุณติดตั้ง 3.0.0 ไว้แล้วเปิดไม่ขึ้น รุ่นนี้แก้ให้แล้ว

---

Fixes a serious bug: **nothing appeared when you first opened the app.**

The licence dialog was shown before the application had started pumping messages, so the
window was never actually created. `ShowDialog` waited for an answer from a dialog that
did not exist, and the app sat there: no window, no error, just a live process.

The main window now opens first and the licence appears over it. Any future startup
failure is shown and written to `%APPDATA%\RovOverlayTool3\startup-error.log` instead of
disappearing silently.

If you installed 3.0.0 and it would not open, this is the fix.
