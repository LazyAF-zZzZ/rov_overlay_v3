# ROV Overlay Tool 3.0.13

## สถิติของทีม

หน้าของแต่ละทีมมีแท็บใหม่ **สถิติ** ข้างแท็บโปรไฟล์ รวมทุกอย่างที่แอปเก็บไว้เกี่ยวกับทีมนั้น

- **ผลงาน**: ซีรีส์และเกมที่ชนะ/แพ้ พร้อมอัตราชนะ และผลซีรีส์ 5 คู่ล่าสุด
- **ฝั่งน้ำเงิน / ฝั่งแดง**: ชนะ-แพ้ตอนเล่นแต่ละฝั่ง
- **ฮีโร่**: ฮีโร่ที่เลือก (กี่เกม อัตราพิค อัตราชนะ) ฮีโร่ที่ทีมนี้แบน และฮีโร่ที่โดนแบนใส่
- **สถิติกับคู่แข่งแต่ละทีม**: ซีรีส์ เกม และผลที่เจอกันล่าสุด กดชื่อคู่แข่งเพื่อเปิดหน้าทีมนั้น
- **ฮีโร่ของผู้เล่นแต่ละคน**: ฮีโร่ที่ผู้เล่นแต่ละคนใช้บ่อยที่สุด พร้อมอัตราชนะ
- **เลือกทัวร์นาเมนต์ได้**: ดูรวมทุกทัวร์นาเมนต์ หรือเฉพาะรายการเดียว
- ตัวเลขอัปเดตเองเมื่อผลหรือดราฟต์เปลี่ยน

> **สถิติฝั่งและฮีโร่ของผู้เล่นนับตั้งแต่เวอร์ชันนี้เป็นต้นไป** เกมก่อนหน้านี้ไม่ได้บันทึกว่าทีมเล่นฝั่งไหนบนจอ
> หรือใครนั่งแถวไหน จึงไม่เดาย้อนหลัง ส่วนผลงาน ฮีโร่ และสถิติกับคู่แข่ง นับทุกเกมที่เคยเล่นไปแล้ว

> อัปเดตนี้จะไม่ติดตั้งเอง: กดเลขเวอร์ชันที่แถบด้านบน แล้วกด **อัปเดตเลย** ตอนที่ไม่ได้ออกอากาศ
> คู่มือในแอปอัปเดตตามแล้วทั้งสองภาษา

## Team statistics

Every team page has a new **Statistics** tab beside Profile, with everything the app knows
about that team.

- **Record**: series and games won and lost, with win rates, and the last 5 series.
- **Blue side / red side**: the win–loss record on each side.
- **Heroes**: heroes picked (games, pick rate, win rate), heroes this team banned, and heroes
  banned against it.
- **Record vs each opponent**: series, games and the last meeting. Click an opponent to open
  their team page.
- **Player hero pools**: each player's most-played heroes, with win rates.
- **Tournament filter**: all tournaments together, or just one.
- The numbers update by themselves when a result or draft changes.

> **Side records and player hero pools count from this version on.** Earlier games did not
> record which side a team played on screen or who sat in each row, so they are not guessed.
> Records, heroes and opponents count every game already played.

> This update does not install by itself: press the version number in the title bar, then
> **Update now**, when you are not on air. The in-app guide has been updated in both languages.
