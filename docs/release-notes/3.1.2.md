# ROV Overlay Tool 3.1.2

## หน้าตั้งค่าสั้นลง

เอาสองกล่องที่ไม่ได้ใช้ออกจากหน้า **ตั้งค่า**

- **ข้อมูลของคุณ** ที่โชว์ที่อยู่โฟลเดอร์ข้อมูลกับโฟลเดอร์รูป พร้อมปุ่มเปิดโฟลเดอร์
- **ย้ายข้อมูลจากเวอร์ชัน 2** ที่ให้ชี้โฟลเดอร์ของเวอร์ชัน 2 แล้วนำเข้า

หน้าตั้งค่าตอนนี้เหลือ ภาษา · สำรองและกู้คืนข้อมูล · อัปเดต · เซิร์ฟเวอร์ · บันทึกการทำงาน · เกี่ยวกับ

**ยังย้ายข้อมูลจากเวอร์ชัน 2 ได้** ที่เวอร์ชัน 2 กดสำรองข้อมูลเก็บไฟล์ `.json` ไว้ แล้วมากด **กู้คืน**
ที่แอปนี้ ไฟล์เป็นแบบเดียวกัน คู่มือในแอปเขียนขั้นตอนใหม่ไว้แล้วทั้งสองภาษา
ส่วนที่อยู่ของโฟลเดอร์ข้อมูล ดูได้ในคู่มือหัวข้อ "ไฟล์ของคุณอยู่ที่ไหน"

> อัปเดตนี้จะไม่ติดตั้งเอง: กดเลขเวอร์ชันที่แถบด้านบน แล้วกด **อัปเดตเลย** ตอนที่ไม่ได้ออกอากาศ

## A shorter Settings screen

Two boxes nobody used are gone from **SETTINGS**:

- **Your data**, which showed the data and uploaded-images folder paths with Open folder buttons.
- **Bring your v2 data across**, which pointed at a v2 folder and imported from it.

Settings is now: Language · Backup and restore · Updates · Server · Log · About.

**Moving from version 2 still works.** In v2, save a backup and keep the `.json` file, then press
**Restore** in this app — it is the same file format. The in-app guide has the new steps in both
languages. The folder paths are in the guide too, under "Where your files are".

> This update does not install by itself: press the version number in the title bar, then
> **Update now**, when you are not on air.
