# ROV Overlay Tool 3.0.3

## แก้เสียงดังรัวตอนสลับรอบ

สลับจากรอบ 1 ไปรอบ 2 แล้วกลับมารอบ 1 เสียงพิคและแบนเคยดังพร้อมกันทั้งกระดาน

overlay เล่นเสียงทุกครั้งที่ช่องใดช่องหนึ่งเปลี่ยนฮีโร่ การสลับรอบคือการโหลดดราฟต์ที่บันทึกไว้
มาทั้งกระดานในครั้งเดียว ช่องเปลี่ยนพร้อมกันสิบแปดช่อง เสียงจึงดังสิบแปดเสียงซ้อนกัน

ตอนนี้เวลากระดานมาทั้งกระดาน overlay จะเงียบเฉพาะอัปเดตนั้น แล้วกลับมาดังปกติทันที
การดราฟต์จริงไม่เปลี่ยน พิคทีละตัวก็ยังมีเสียงทุกตัวเหมือนเดิม

> **หลังอัปเดต ให้รีเฟรชแคชของ browser source ใน OBS ด้วย**
> คลิกขวาที่ source แล้วเลือก `Refresh cache of current page`
> ไม่อย่างนั้น OBS จะยังใช้สคริปต์ตัวเก่าที่จำไว้

## ย้ายไปมาระหว่างสายการแข่งกับหน้าคุมงานได้ไวขึ้น

- **หน้าทัวร์นาเมนต์มีรายการคู่ที่พร้อมแข่งแล้ว** กดปุ่มเล่นข้างคู่ไหนก็เอาขึ้นจอ
  แล้วเข้าหน้าคุมงานให้เลย ไม่ต้องเข้าไปที่สายการแข่งก่อน
- **สายการแข่งจัดกลางจอ** ทัวร์นาเมนต์เล็ก ๆ ไม่ไปกองอยู่มุมซ้ายบนอีกแล้ว
- **ช่องชื่อแมตช์กว้างพอ** อ่านได้ครบไม่ตัดกลางคำ

## Fixes the sounds firing all at once on a round switch

Switching round 1 to round 2, and back, played every pick and ban sound together.

The overlay plays a sound whenever a slot's hero changes, and a round switch loads a whole
recorded draft in one update: eighteen slots change, eighteen sounds fire. A board arriving
all at once is now silent for that one update, and sound returns immediately after. Real
drafting is unchanged — every hero you pick still sounds exactly once.

> **After updating, refresh the browser source cache in OBS** (right-click the source →
> `Refresh cache of current page`), or it will keep running the script it remembers.

## Moving between the bracket and the Control Panel

- **The tournament page lists the matches ready to play**, each with a button that puts it
  on air and opens the Control Panel — no need to go through the bracket.
- **The bracket is centred**, so a small tournament is no longer one card in the corner.
- **The match title field fits the whole title** without clipping mid-word.
