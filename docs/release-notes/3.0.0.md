# ROV Overlay Tool 3.0.0

หน้าจอคุมงานเป็นแอปจริงแล้ว ไม่ใช่หน้าเว็บอีกต่อไป **overlay ทุกอันเหมือนเดิมทุกอย่าง
scene เดิมใน OBS ใช้ต่อได้เลย ไม่ต้องแก้ URL**

## มีอะไรใหม่

- **แอปสำหรับ Windows จริง ๆ** หน้าคุมงาน ทะเบียนทีม สาย สถิติ ดราฟต์ที่บันทึกไว้
  คู่มือ ทั้งหมดอยู่ในแอปเดียว เปิดเร็วกว่าเดิม และไม่ต้องเปิดเบราว์เซอร์ค้างไว้
- **อัปเดตเอง** เวอร์ชันใหม่จะโหลดไว้เงียบ ๆ แล้วติดตั้งตอนคุณปิดแอป
  **แอปจะไม่รีสตาร์ตเองระหว่างคุณออกอากาศ**
- **ย้ายข้อมูลจากเวอร์ชัน 2 ได้** ทีม โลโก้ ทัวร์นาเมนต์ สาย และดราฟต์ทุกชุด
  ไปที่ ตั้งค่า แล้วกดนำเข้า โฟลเดอร์ของเวอร์ชัน 2 ถูกอ่านอย่างเดียว ไม่ถูกแก้
- **คีย์ลัดใช้ได้ทั้งเครื่อง** ไม่ต้องคลิกที่หน้าต่างแอปก่อน
- **ไทย/อังกฤษ** สลับได้ทุกเมื่อ
- ข้อมูลทุกอย่างยังอยู่ในเครื่องคุณเหมือนเดิม ไม่ต้องสมัคร ไม่ต้องต่อเน็ต

## วิธีติดตั้ง

1. โหลด `RovOverlayTool3-win-Setup.exe` แล้วเปิด
2. ถ้า Windows เตือน ให้กด `More info` แล้ว `Run anyway` (ไฟล์ยังไม่ได้เซ็นใบรับรอง)
3. ครั้งแรกจะมีหน้าต่างเงื่อนไขการใช้งานให้กดยอมรับ

เวอร์ชัน 2 ยังอยู่ในเครื่องเหมือนเดิม ลบเมื่อไหร่ก็ได้หลังจากนำเข้าข้อมูลเรียบร้อยแล้ว

---

The operator screens are a real Windows application now instead of web pages. **Every
overlay is unchanged — existing OBS scenes keep working with the same URLs.**

- One native app for the control panel, teams, brackets, statistics, recorded drafts and
  the guide.
- **Updates itself**: a new version downloads quietly and goes in when you close the app.
  It never restarts itself while you are on air.
- **Brings your v2 data across** — teams, logos, tournaments, brackets and every recorded
  draft. Settings → Import. Your v2 folder is only read, never changed.
- System-wide hotkeys, Thai and English, and all data still on your own PC.

Download `RovOverlayTool3-win-Setup.exe` below. SmartScreen will warn because the file is
not code-signed: `More info` → `Run anyway`.
