# ROV Overlay Tool 3.0.9

## อัปเดตจะไม่ติดตั้งเองอีกต่อไป

เมื่อก่อนเวอร์ชันใหม่ที่ดาวน์โหลดไว้จะถูกติดตั้งเองตอนคุณปิดแอป ตอนนี้ไม่มีแล้ว

- แอปยังหาและดาวน์โหลดเวอร์ชันใหม่ให้เงียบ ๆ เหมือนเดิม
- แต่ **จะไม่ติดตั้งจนกว่าคุณจะกด อัปเดตเลย** ไม่ติดตั้งตอนปิดแอป และไม่ติดตั้งตอนเปิดแอป
- กด **ไว้ก่อน** ได้ไม่เสียอะไร เลขเวอร์ชันจะค้างอยู่ที่แถบด้านบน กดเมื่อไหร่ก็กลับมาติดตั้งได้ ตอนที่ไม่ได้ออกอากาศ

> เวอร์ชันนี้เองยังถูกติดตั้งแบบเดิม (ตอนปิดแอป) เพราะแอปเวอร์ชันก่อนหน้าเป็นคนติดตั้ง
> ตั้งแต่เวอร์ชันนี้เป็นต้นไป จะไม่มีอะไรติดตั้งเองอีก

## Updates no longer install by themselves

A downloaded version used to go in by itself when you closed the app. Not any more.

- The app still finds and downloads new versions quietly, as before.
- But **nothing is installed until you press Update now** — not when the app closes, and not when it starts.
- **Later** costs nothing. The version number stays in the title bar; press it whenever you are ready and not on air.

> This version itself still arrives the old way, on close, because the previous version is
> the one putting it in. From this version on, nothing installs by itself.
