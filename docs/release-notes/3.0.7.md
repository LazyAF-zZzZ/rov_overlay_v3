# ROV Overlay Tool 3.0.7

## ตัวที่เลือกไว้แต่ยังไม่ยืนยัน จะเป็นขาวดำ

ตั้งแต่ 3.0.6 ช่องพิคต้องกดปุ่ม ✓ ยืนยันก่อน เสียงถึงจะดัง แต่ระหว่างที่ยังไม่กด
ภาพฮีโร่ขึ้นจอเหมือนตัวที่ล็อกไปแล้วทุกอย่าง คนดูจึงแยกไม่ออกว่าอันไหนจบแล้ว อันไหนยังสลับได้อยู่

ตอนนี้ช่องที่ยังไม่ยืนยันจะขึ้นเป็น **ขาวดำ ความทึบ 70%** พอกด ✓ สีจะไล่กลับมาเต็มพร้อมเสียงและอนิเมชัน
การ "ล็อก" เลยมีภาพให้เห็นด้วยตัวมันเอง ไม่ต้องอธิบาย

ใช้ได้ทั้ง overlay 1080p และ 1440p ไม่ต้องตั้งค่าอะไรเพิ่ม

> **ถ้าเปิดใน OBS อยู่แล้วยังเห็นเป็นสีปกติ** ให้คลิกขวาที่ browser source แล้วกด
> *Refresh cache of current page* หนึ่งครั้ง OBS เก็บไฟล์ CSS ไว้ค่อนข้างเหนียว

คู่มือในแอปอัปเดตตามแล้วทั้งสองภาษา และเพิ่มหัวข้อ **ย้ายมาจากเวอร์ชัน 2** ซึ่งมีมาตั้งแต่แรก
แต่ไม่เคยเขียนไว้ในคู่มือ

## A pick that is chosen but not confirmed now shows in grey

Since 3.0.6 a pick needs the ✓ button before the sound plays — but until it was pressed the
hero looked exactly like one already locked in. Viewers could not tell what was final and
what the teams were still swapping around.

An unconfirmed pick is now drawn **greyscale at 70% opacity**. Pressing ✓ brings the colour
back with the sound and the reveal animation, so locking a hero in is something you can see
as well as hear.

Both the 1080p and the 1440p overlay, with nothing to configure.

> **If it still looks full colour in OBS**, right-click the browser source and pick
> *Refresh cache of current page* once. OBS holds on to CSS hard.

The in-app guide has been updated in both languages, and gained a **Coming from version 2**
section — importing your v2 teams, tournaments and drafts has been in the app since the
start, but the guide never said so.
