# ROV Overlay Tool 3.0.4

หน้า **ลิงก์ OBS** บอกเรื่องเสียงชัดขึ้น

- **source ไหนมีเสียง เห็นได้จากในรายการเลย** Overlay 1080p กับ Overlay 1440p จะติดป้าย
  "มีเสียง" ไว้ เพราะมีแค่สองอันนี้ที่ลิงก์ลงท้ายด้วย `?sfx=1`
  (ถ้าให้ทุก source มีเสียง overlay กับหน้าผลจะเล่นเสียงซ้อนกันเอง)
- **ใต้รายการมีสองเรื่องที่ทำให้เสียงดูเหมือนพัง ทั้งที่ไม่ได้พัง**
  - ต้องติ๊ก `Control audio via OBS` ในหน้าตั้งค่าของ source นั้นด้วย เสียงถึงจะออกอากาศ
  - หลังแอปอัปเดต ต้องคลิกขวาที่ source แล้วเลือก `Refresh cache of current page`
    ไม่อย่างนั้น OBS จะยังใช้ overlay ตัวเก่าที่จำไว้

---

The **OBS sources** panel is clearer about sound.

- **You can see which sources carry it.** Overlay 1080p and Overlay 1440p now show a
  SOUND badge, because those are the only two URLs ending in `?sfx=1`. Sound is opt-in per
  URL, or the overlays and the result screen would echo each other.
- **Two reminders under the list**, for the things that make working sound look broken:
  - `Control audio via OBS` has to be ticked in that source's properties.
  - After the app updates, right-click the source and choose
    `Refresh cache of current page`, or OBS keeps running the overlay it remembers.
