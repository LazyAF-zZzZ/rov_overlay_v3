# ROV Overlay Tool 3.0.2

ทำให้การสลับไปมาระหว่าง **สายการแข่ง** กับ **หน้าคุมงาน** ลื่นขึ้น ซึ่งเป็นสิ่งที่ต้องทำบ่อยที่สุดตอนงานจริง

## เปลี่ยนอะไรบ้าง

- **ดับเบิลคลิกที่คู่ในสายการแข่ง** (หรือกดปุ่มเล่นบนคู่นั้น) จะเอาคู่นั้นขึ้นจอ
  **แล้วพาเข้าหน้าคุมงานให้เลย** เหมือนเวอร์ชัน 2
  ปุ่มเดิมเป็นไอคอนเล็กมากจนแทบไม่มีใครเห็น ตอนนี้เป็นปุ่มจริงและไม่ทับช่องกรอกคะแนนแล้ว
- **มีทางกลับ** แถบ ออนแอร์ ในหน้าคุมงานมีปุ่ม **ไปที่สายการแข่ง** ของคู่ที่กำลังคุมอยู่
  กด Esc เพื่อกลับมาที่ดราฟต์ที่ค้างไว้ได้ทันที
  เมื่อก่อนต้องไล่ หน้าแรก → ทัวร์นาเมนต์ → สายการแข่ง ใหม่ทุกครั้งที่จบเกม
- **หน้าสถิติและประวัติพิค/แบนใช้ไอคอนฮีโร่** แทนรูปเต็มตัว เหมือนที่หน้าคุมงานใช้อยู่แล้ว
  รูปสี่เหลี่ยมพอดีช่อง และไฟล์เล็กลงมาก
- แก้ดราฟต์ที่จบแล้วขึ้นว่า "เฟส 17 / 16"

---

Makes moving between the **bracket** and the **Control Panel** quick, which is the thing
you do most during an event.

- **Double-click a match** in the bracket (or press its play button) to put it on air
  **and go straight to the Control Panel with it**, as v2 did. The old button was a tiny
  icon almost nobody found; it is a real button now, and no longer covers the score boxes.
- **There is a way back.** The ON AIR strip in the Control Panel has a button to the
  bracket of the match it is driving, and Esc returns you to the draft where you left it.
  Before, getting back meant Home → the tournament → the bracket, after every game.
- **Analytics and the pick/ban history use the hero icons** instead of the full portraits,
  as the Control Panel already did.
- Fixed a finished draft reading "Phase 17 / 16".
