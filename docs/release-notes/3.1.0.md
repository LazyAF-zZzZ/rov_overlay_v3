# ROV Overlay Tool 3.1.0

## คีย์ลัดใช้ได้ทุกที่ และเปิดไว้ตั้งแต่แรก

คีย์ลัดทำงานแม้ตอนอยู่ใน OBS หรือในเกม ไม่ต้องสลับกลับมาที่แอป และตอนนี้เปิดไว้เป็นค่าเริ่มต้น
อยู่ด้านบนสุดของหน้า **คีย์ลัด**

**จบเกมได้จาก OBS:** มีคีย์ลัดสำหรับคะแนนและรอบแล้ว ทำงานเหมือนปุ่มข้างคะแนนและลูกศรรอบทุกอย่าง
แต้มที่ปิดซีรีส์จะขึ้นแถบ **ซีรีส์จบแล้ว** พร้อมปุ่มขึ้นจอคู่ถัดไปบนหน้าคุมงานเหมือนกดปุ่มเอง

**ทุกปุ่มอยู่ใต้มือซ้ายมือเดียว:** กด Ctrl + Alt ค้างไว้ แล้ว

```
 1  2         +1 น้ำเงิน / แดง
 Q  W   E  R  −1 น้ำเงิน / แดง        เฟสดราฟต์ก่อนหน้า / ถัดไป
 A  S   D  F  รอบก่อนหน้า / ถัดไป      พัก-เดินนาฬิกา / ซ่อน-แสดงแบนเนอร์
 Z            ย้อนพิคหรือแบน
```

ซ้ายคือน้ำเงิน ขวาคือแดง เหมือนบนจอ มืออีกข้างอยู่ที่เมาส์ได้ตลอด

- น้ำเงินกับแดงคือฝั่งบนจอตอนที่กด ทีมสลับฝั่งหลังจบทุกเกม ถ้าจะถอนแต้มที่เพิ่งให้ ให้กด −1 ของฝั่งที่ทีมนั้นอยู่ตอนนี้
- ถ้าเคยใช้คีย์ลัดชุดเดิม (Ctrl + Alt + H, Space และลูกศร) จะย้ายมาชุดนี้เอง ปุ่มที่ตั้งเองไว้ไม่ถูกเปลี่ยน
- ปุ่มที่โปรแกรมอื่นจองอยู่จะขึ้นสีแดงบนหน้าคีย์ลัด กด **เปลี่ยน** เพื่อเลือกปุ่มใหม่ หรือเอาเครื่องหมาย **เปิดใช้งาน** ออกถ้าไม่ต้องการ
- คีย์ลัดหน้าคุมงานแบบเดิม (แตะ Alt, Space, ลูกศร, Ctrl + Z) ยังอยู่ ใช้ได้ตอนแอปอยู่หน้าสุด

## แก้ไข

- เมื่อแอปอยู่หน้าสุด การกดคีย์ลัด Ctrl + Alt ทำให้แบนเนอร์เปิด/ปิดไปด้วยเพราะนับเป็นการแตะ Alt ตอนนี้แตะ Alt เดี่ยวๆ เท่านั้นที่นับ

> อัปเดตนี้จะไม่ติดตั้งเอง: กดเลขเวอร์ชันที่แถบด้านบน แล้วกด **อัปเดตเลย** ตอนที่ไม่ได้ออกอากาศ
> คู่มือในแอปอัปเดตตามแล้วทั้งสองภาษา

## Hotkeys work everywhere, and they are on from the start

Hotkeys work even while you are in OBS or the game, with no switching back to the app, and they are
now on by default. They are at the top of the **Hotkeys** page.

**End a game from OBS:** there are hotkeys for the score and the rounds. They do exactly what the
buttons beside the score and the round arrows do. A point that ends the series brings up the
**SERIES OVER** bar, with the next match ready to put on air, just as the button does.

**Every key under one hand:** hold Ctrl + Alt, then

```
 1  2         +1 blue / red
 Q  W   E  R  −1 blue / red           previous / next draft phase
 A  S   D  F  previous / next round   pause timer / show-hide banner
 Z            undo pick or ban
```

Blue is on the left and red on the right, like the screen, so your other hand stays on the mouse.

- Blue and red mean the side on screen when you press. Teams swap sides after every game, so to take
  back a point you just gave, press −1 for the side that team is on now.
- If you used the old keys (Ctrl + Alt + H, Space and the arrows), they move to this layout by
  themselves. Keys you chose yourself stay as they are.
- A key another program already holds is shown in red on the Hotkeys page. Press **Change** to pick
  another, or untick **Switched on** if you don't want hotkeys.
- The Control Panel's own keys (tap Alt, Space, the arrows, Ctrl + Z) are still there, for while the
  app is in front.
