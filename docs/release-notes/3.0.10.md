# ROV Overlay Tool 3.0.10

## ผู้ชนะนับจากคะแนน ไม่ต้องเลือกเอง

ปุ่ม **จบเกม → ทีมที่ชนะ** และหน้าต่างยืนยันถูกเอาออกแล้ว ตอนนี้ข้างช่องคะแนนของแต่ละทีมมีปุ่ม **+1**

- **จบเกมแล้ว กด +1 ข้างคะแนนของทีมที่ชนะ** กดครั้งเดียว ไม่มีถามยืนยัน
  โปรแกรมให้แต้ม บันทึกว่าใครชนะเกมนี้ เก็บดราฟต์ไว้กับเกมนี้ แล้วขึ้นเกมถัดไปบนกระดานให้เลย
- **ผู้ชนะซีรีส์นับจากคะแนน** เมื่อทีมไหนชนะครบตามที่ต้องการ (Bo3 = 2 เกม, Bo5 = 3 เกม)
  แผงจะขึ้น **ซีรีส์จบแล้ว · PSG Esports ชนะซีรีส์ 2–1** พร้อมคู่ถัดไปและปุ่ม **ขึ้นจอ**
- **พิมพ์ในช่องคะแนนแค่แก้ตัวเลข** ไม่เลื่อนกระดาน พิมพ์ผิดจึงไม่ข้ามเกม
- กดผิดฝั่ง? กด `<` ที่ ROUND เพื่อพาเกมกลับมา แล้วแก้แต้มในช่องคะแนน

> อัปเดตนี้จะไม่ติดตั้งเอง: กดเลขเวอร์ชันที่แถบด้านบน แล้วกด **อัปเดตเลย** ตอนที่ไม่ได้ออกอากาศ
>
> คู่มือในแอปอัปเดตตามแล้วทั้งสองภาษา

## The winner is counted from the score

The **GAME OVER → team won** buttons and their confirmation are gone. Each team's score now has
a **+1** button beside it.

- **When a game ends, press +1 beside the winning team's score.** One press, no confirmation.
  The app gives the point, records who won the game, keeps the draft with that game and puts
  the next game on the board.
- **The series winner is counted from the score.** When a team reaches the wins it needs
  (2 in a Bo3, 3 in a Bo5), the panel shows **SERIES OVER · PSG Esports win the series 2–1**
  with the next match and **Put on air**.
- **Typing in the score box only corrects the number.** It never moves the board, so a typo
  cannot skip a game.
- Pressed the wrong side? `<` on ROUND brings the game back, and the score box takes the point off.

> This update does not install by itself: press the version number in the title bar, then
> **Update now**, when you are not on air.
