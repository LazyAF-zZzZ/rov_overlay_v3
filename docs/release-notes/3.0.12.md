# ROV Overlay Tool 3.0.12

## ปุ่ม −1 ข้างคะแนน

กด +1 ผิดไปแล้วแก้ได้ในปุ่มเดียว ข้างคะแนนของแต่ละทีมมีปุ่ม **−1** เป็นการย้อน +1 ตรงตัว

- **ถอนแต้ม** และล้างผู้ชนะของเกมนั้น
- **เอาเกมนั้นกลับขึ้นกระดาน** พร้อมดราฟต์และฝั่งเดิม
- ถ้าแต้มนั้นเคยปิดซีรีส์ **ซีรีส์จะกลับมาแข่งต่อ** และผู้ชนะถูกถอนออกจากคู่ถัดไปในสายด้วย
- **คะแนนเป็น 0 กดไม่ได้** ปุ่มจะเป็นสีจาง
- ถอนได้เฉพาะ **เกมล่าสุด** ถ้าอีกทีมชนะเกมล่าสุด ต้องถอนแต้มของทีมนั้นก่อน
  (ถอนเกมเก่ากว่าจะทำให้เลขเกมเลื่อน แล้วดราฟต์ใหม่จะไปทับเกมที่เล่นไปแล้ว)

## แก้ไข: สถิติยังนับผลของคู่ที่ถูกล้างไปแล้ว

ถ้าแก้ผลของคู่ก่อนหน้า หลังจากคู่ถัดไปในสายแข่งไปแล้ว สายจะล้างผลของคู่ถัดไปเป็น 0–0
แต่ผู้ชนะของเกมในคู่นั้นยังค้างอยู่ อัตราชนะของฮีโร่ สถิติของทีม หัวต่อหัว และประวัติพิคแบน
จึงยังนับผลแพ้ชนะที่สายไม่ยอมรับแล้ว

ตอนนี้ผู้ชนะของเกมในคู่ที่ถูกล้างจะถูกล้างไปด้วย ดราฟต์ยังอยู่ อัตราพิคและแบนจึงยังนับสิ่งที่เล่นไปจริง

> อัปเดตนี้จะไม่ติดตั้งเอง: กดเลขเวอร์ชันที่แถบด้านบน แล้วกด **อัปเดตเลย** ตอนที่ไม่ได้ออกอากาศ
> คู่มือในแอปอัปเดตตามแล้วทั้งสองภาษา

## −1 beside the score

A mistaken +1 is now fixed with one press. Each team's score has a **−1** button beside it,
the exact undo of +1.

- **Takes the point back** and clears that game's winner.
- **Puts that game back on the board** with its draft and sides.
- If that point had ended the series, **the series opens again** and the winner is pulled back
  out of the next match in the bracket.
- **Greyed out and unpressable when the score is 0.**
- Only undoes **the most recent game**. If the other team won the last game, take that point
  back first. (Undoing an older game would renumber the games, and the next draft would be
  written over a game that was really played.)

## Fixed: statistics still counted a match that had been reset

Correcting an earlier result after the next match in the bracket had been played reset that
match to 0–0, but its games kept their winners. Hero win rates, team statistics, Head to head
and Pick / ban history went on counting a result the bracket no longer had.

The winners of a reset match's games are now cleared too. The drafts stay, so pick and ban
rates still count what was really played.
