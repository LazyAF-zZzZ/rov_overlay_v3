# ROV Overlay Tool 3.0.8

## จบเกมด้วยปุ่มเดียว

เมื่อก่อนจบเกมหนึ่งต้องทำสองอย่างแยกกัน: บวกแต้มในช่องคะแนน แล้วกด `>` ที่ ROUND
ลืมอย่างแรก เกมนั้นไม่มีผู้ชนะ สถิติอัตราชนะหายไป ลืมอย่างหลัง ดราฟต์เกมถัดไปเขียนทับเกมที่เพิ่งจบ

ตอนนี้ที่หัวแผงดราฟต์มีปุ่ม **จบเกม → *ทีมที่* ชนะ** กดแล้วยืนยันหนึ่งครั้ง โปรแกรมจะ

- ให้แต้มฝั่งนั้น และบันทึกว่าใครชนะเกมนี้
- เก็บดราฟต์ไว้กับเกมนี้
- ขึ้นเกมถัดไปบนกระดานให้เลย

กดผิดฝั่งก็แก้ได้: `<` ที่ ROUND พาเกมกลับมา แล้วแก้แต้มในช่องคะแนน
เกมที่มีผลแล้วจะไม่ถูกนับซ้ำ และถ้าสลับฝั่งไว้ แต้มจะไปที่ทีมที่อยู่ฝั่งน้ำเงินบนจอจริง ๆ

**เมื่อเกมตัดสินซีรีส์** จะไม่มีเกมที่ 3 งอกขึ้นมา แผงจะขึ้น **ซีรีส์จบแล้ว**
พร้อมคู่ถัดไปที่พร้อมเล่นและปุ่ม **ขึ้นจอ** ไม่ต้องกลับไปที่สายการแข่ง

## หน้าคุมงานโล่งขึ้น

- **ส่วนตั้งค่าทีมพับเก็บเองเมื่อเริ่มดราฟต์** ชื่อทีม โลโก้ ชื่อผู้เล่น และเลน ช่องพิคได้ที่เต็ม กด **ตั้งค่าทีม** เพื่อเปิดกลับมา
- ระดับเสียงพับไว้ใต้ **เสียงเอฟเฟกต์**
- ปุ่ม **เริ่ม** อยู่แถวของตัวเอง ปุ่มรีเซ็ตนาฬิกาย้ายไปท้ายแถวล่าง ไม่อยู่ติดกันแล้ว
- **พัก / ไปต่อ** รวมเป็นปุ่มเดียว
- **ล้างแมตช์** แยกไปอยู่ขวาสุดคนเดียว ปุ่มสลับเป็นไอคอน

## หน้าแรกบอกว่าตอนนี้อะไรออกอากาศ

หน้าแรกแสดงคู่ที่กำลังออกอากาศพร้อมสกอร์และปุ่ม **ไปหน้าคุมงาน**
และคู่ที่พร้อมเล่นได้สูงสุดหกคู่ กดปุ่มเล่นแล้วขึ้นจอได้เลย รายการที่กำลังออกอากาศขึ้นก่อน

## แก้ไข

- หลังเอาคู่ใหม่ขึ้นจอจากหน้าคุมงาน ช่อง **ชื่อแมตช์** ยังค้างชื่อคู่ก่อนหน้า ตอนนี้ตามคู่ใหม่แล้ว

> คู่มือในแอปอัปเดตตามแล้วทั้งสองภาษา

## Ending a game is one button

Ending a game used to take two separate actions: add the point in the score box, then press
`>` on ROUND. Forget the first and the game had no winner, so win rates lost it; forget the
second and the next draft was written over the game just played.

The draft panel now has **GAME OVER → *team* won**. After one confirmation it

- gives that side the point and records who won the game,
- keeps the draft with that game,
- and puts the next game on the board.

Pressed the wrong side? `<` on ROUND brings the game back, and the score box takes the point
off. A game that already has a result is never counted twice, and after Switch Teams the point
goes to the team actually shown on the blue side.

**When a game decides the series**, no game 3 appears. The panel shows **SERIES OVER** with the
next match that is ready to play and a **Put on air** button — no trip to the bracket.

## A calmer Control Panel

- **Team setup folds away when the draft starts** — names, logos, nicknames and lanes — so the picks get the room. **Team setup** opens it again.
- Sound levels are folded under **SOUND EFFECTS**.
- **START** has its own row; the clock reset moved to the far end of the row below it.
- **PAUSE / RESUME** is one button.
- **RESET MATCH** sits alone at the far right, and the swap buttons are icons.

## Home shows what is live

Home now shows the match on air with its score and **Go to Control**, and up to six matches
ready to play, each one press from going on air. The tournament on air comes first.
